# Программа 1 — C++ — разбор вместе с преподавателем

## Тематика: бесплатная доставка в интернет-магазине

### Требования

Бесплатная доставка предоставляется, если:

```text
VIP = true
ИЛИ
сумма заказа >= 5000
```

Пример:

| VIP | Сумма | Бесплатная доставка |
| --- | ----: | ------------------- |
| Нет |  1000 | Нет                 |
| Нет |  5000 | Да                  |
| Да  |  1000 | Да                  |
| Да  |  5000 | Да                  |

### Шаг 1. Определяем классы

Для VIP:

```text
VIP = Да
VIP = Нет
```

Для суммы:

```text
< 5000
>= 5000
```

Получаем четыре комбинации:

```text
Нет + < 5000
Нет + >= 5000
Да + < 5000
Да + >= 5000
```

Это уже простая **Decision Table**.

### Шаг 2. Выбираем представителей классов

Например:

```text
VIP = Нет, сумма = 3000
VIP = Нет, сумма = 5000
VIP = Да, сумма = 3000
VIP = Да, сумма = 5000
```

### Шаг 3. Тестируем

Студенты должны получить:

```text
Нет + 3000 → платная доставка
Нет + 5000 → бесплатная
Да + 3000 → бесплатная
Да + 5000 → бесплатная
```
