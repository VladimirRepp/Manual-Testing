# Программа 1 — C# — разбор вместе с преподавателем

## Тематика: регистрация игрового аккаунта

### Требования

Игрок регистрируется в игре.

Логин:

* обязательный;
* минимум 3 символа;
* максимум 15 символов.

Пароль:

* обязательный;
* минимум 6 символов.

Возраст:

* от 12 лет.

### Вместе со студентами составляем Test Case

Например:

**Название:**

```text
Регистрация с корректными данными
```

**Preconditions:**

```text
Программа запущена.
Пользователь не зарегистрирован.
```

**Test Data:**

```text
Login: Player123
Password: qwerty123
Age: 18
```

**Steps:**

```text
1. Ввести Player123.
2. Ввести qwerty123.
3. Ввести 18.
4. Нажать Register.
```

**Expected Result:**

```text
Аккаунт успешно создан.
```

После этого выполняем программу и записываем **Actual Result**.

Затем делаем несколько Test Case:

1. корректная регистрация;
2. слишком короткий логин;
3. слишком длинный логин;
4. пустой пароль;
5. возраст 11;
6. возраст 12;
7. возраст 13.
