# Занятие 3. Позитивное и негативное тестирование

## Что отрабатываем

Главная идея занятия:

> Для каждой функции нужно проверить не только то, что пользователь делает правильно, но и то, что произойдет при ошибочном вводе.

---

# Программа 1 — C++ — разбор вместе с преподавателем

## Тематика: банковское приложение

### Требования

Пользователь может перевести деньги.

* Баланс: 10 000 рублей.
* Минимальная сумма перевода: 1 рубль.
* Максимальная сумма: 10 000 рублей.
* Нельзя перевести больше, чем есть на балансе.
* После успешного перевода баланс уменьшается.
* При ошибке баланс не должен изменяться.

### Что проверяем

**Позитивные сценарии:**

```text
1
100
5000
10000
```

**Негативные:**

```text
0
-1
10001
15000
```

Также:

```text
баланс 10000
перевод 10001
```
