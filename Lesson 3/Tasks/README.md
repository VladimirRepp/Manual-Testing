# Занятие 4. Граничные значения

## Что отрабатываем

Главный принцип:

Если программа принимает значения:

```text
18 ... 65
```

недостаточно проверить:

```text
25
```

Нужно проверить:

```text
17
18
19
64
65
66
```

То есть:

* ниже границы;
* сама граница;
* около границы;
* внутри диапазона;
* около второй границы;
* сама граница;
* выше границы.

# Программа 1 — C# — разбор вместе с преподавателем

## Тематика: система рейтинга игрока

### Требования

Игра принимает рейтинг:

```text
от 1000 до 3000
```

Если рейтинг:

```text
< 1000
```

то он недопустим.

Если:

```text
1000–3000
```

то рейтинг допустим.

Если:

```text
> 3000
```

то он недопустим.

### Вместе составляем проверки

| Ввод | Почему проверяем   |
| ---: | ------------------ |
|  999 | ниже минимума      |
| 1000 | минимум            |
| 1001 | рядом с минимумом  |
| 1500 | внутри диапазона   |
| 2999 | рядом с максимумом |
| 3000 | максимум           |
| 3001 | выше максимума     |

После этого студентам становится очевидно, что **граничные значения — это не просто теория**, а конкретный набор тестов.
